# 拾光日记

手机优先的生活与学习共享网页。呼呼与听听使用各自账号登录后，可以实时查看和更新同一份日历心情、愿望、计划、备忘录、学习进度、对话与笔记；最近操作会显示操作者称呼。

## 本地运行

需要 Node.js 18 或更新版本。

1. 将 `shared.config.example.mjs` 复制为 `shared.config.local.mjs`，设置本地注册邀请码（建议使用随机且不短于 24 位的字符串）。
2. 在 `deepseek.config.local.mjs` 配置本地 DeepSeek Key，或使用环境变量 `DEEPSEEK_API_KEY`。
3. 双击 `启动拾光日记.bat`。
4. 第一个人用“呼呼”注册，第二个人用“听听”注册；两人使用不同的密码和同一个邀请码。共享空间只允许这两个账号。

共享数据写入 `DATA_DIR` 指定的 `shared-data.json`。首次注册的人原浏览器已有的日记、计划、聊天和笔记会导入共享空间；之后另一位登录会加载共享数据。

## 公网部署

项目附有 `render.yaml` 部署配置，建议使用 Render 新加坡区域的常驻 Node Web 服务，并将数据盘挂载到 `/var/data`。部署后会提供 `onrender.com` HTTPS 链接；以后也可绑定自己的域名。服务需要使用支持持久化磁盘的付费方案，免费 Web 服务会休眠且不支持持久化磁盘。

建议把整个 `拾光日记` 文件夹放入私有代码仓库，再在 Render 中创建 Blueprint。首次部署时，在 Render 的环境变量页面填写 `DEEPSEEK_API_KEY`；`APP_INVITE_CODE` 由部署配置生成。不要把 Key 或邀请码写进公开仓库。

服务端环境：

- `NODE_ENV=production`
- `DATA_DIR=/var/data`
- `APP_INVITE_CODE`：仅供呼呼、听听注册的共享邀请码；两人注册后，后续注册自动关闭。
- `DEEPSEEK_API_KEY`：DeepSeek API Key，只保存在服务端。
- 可选 `DEEPSEEK_MODEL`，默认 `deepseek-flash`。

服务端对每个来源限制为每分钟最多 30 次 AI 请求、120 次同步写入；注册限制为每小时 5 次。当前共享空间最多两个账号，后端实时推送数据变化，并保留最近 100 条操作者动态。服务端以单个 Node 实例和持久化数据盘运行；扩成多个实例前需要改用共享数据库和跨实例消息服务。

## 隐私与数据

两个登录用户都能查看共享空间中的对话和日常记录。AI 对话和摘录请求会将相应文本发送到 DeepSeek；账号密码以加盐哈希保存在服务端。登出或会话过期后需要重新登录。请仅与听听分享邀请码，并定期备份服务器数据文件。

## 模块

- **今日**：月历、时段心情、图片日程和分类愿望池。
- **计划**：学习 / 娱乐 / 休息 / 工作 / 生活分类；支持完成、延期、编辑与删除。
- **学习**：每日进阶词汇、词性/释义/例句、打卡、AI 基础与 Agent 知识、开源项目。
- **AI 对话**：会话保存、标记提问者、对话摘录为结构化知识笔记。
- **笔记**：按日期和关键词筛选，编辑、手动关联并查看思维网络。
